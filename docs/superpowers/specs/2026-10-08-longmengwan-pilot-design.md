# 龙梦湾装修选配试点设计

## 目标与边界

在现有 Windows 本地应用上，为员工提供标准户型、合作商家商品、九套方案、替换选配和报价。软件由项目方员工操作，商家交付资料包，业主在员工陪同下查看方案。当前不加入示例 P13；收到龙梦湾 CAD 后核验并按现有 `PLANS` 结构录入真实户型。图片/PDF 户型自动识别不进入本轮首版。

现有 `huxing-design-v2` 存储格式、已保存方案和仓库已有的 12 套户型必须保留。应用默认本地工作，商品照片只有在管理员明确启动生成时才上传至 TRELLIS.2 服务。联网生成的实际部署、依赖许可和单件成本先用真实商品验证，再启用生产流程。

## 商品与模型

一个商品含商家、SKU、名称、类别、宽深高 mm、材质、备注、供货价、业主销售价、可选风格与预算档位、模型来源及审核状态。SKU 在同一商家内唯一。支持选 GLB/GLTF 实际模型；关联贴图的 glTF 需成包导入或先转换 GLB。文件存 IndexedDB，元数据另存本机；不得将模型的 base64 放进 localStorage。

照片路径需录入照片和真实宽深高，经可替换的远程生成适配器请求 TRELLIS.2，保存得到的 GLB 后展示旋转预览。管理员校正朝向、宽深高，点击“确认入库”后才可加入方案。生成失败保留待审核商品，不能默默用方块替代真实模型。未审核商品不参与选配。单视角生成的背面是推测结果，在确认界面明示。

3D 展示沿用现有 Three.js 场景，增加模型加载及资源回收，保留点击、拖动、旋转、碰撞和尺寸约束。无模型的施工材料不伪装为商品模型。

## 户型、方案与预算

每套标准户型有经人工审核的基础布局。员工输入套内面积与交付状态。毛坯房三档每㎡ 650/850/1200 元，包含施工材料、定制柜体、家具家电、运输安装；精装房三档每㎡ 150/350/700 元，只包含家具家电。每档生成现代简约、轻奢、新中式，共九套方案。单价可在内部修改，生成时记录快照，后续调整默认值不改变历史报价。

生成规则基于审核布局的槽位：按类别、尺寸、风格标签、档位与销售价选择已审核商品。不能满足时保留缺项并解释原因；不跨风格补齐，不擅自超预算。员工可替换、移动、删除商品，重新计算报价。每套方案独立保存并可比较。

## 报价与商家结算

商品记录供货价与销售价。业主版仅展示销售价、SKU、规格、数量、备注和适用项目；供货价、差价、商家费率及佣金只在内部视图。每个商家可设置一次性入驻费与按实际成交供货/施工结算额计算的费率，默认 2000 元与 2%，可修改或免收。设计阶段的预计佣金与实际成交结算分开，取消和退款需按实际结算额重算。

毛坯硬装项目按数量、单位、工艺与报价录入，概算与复尺后确认报价分开。精装房不自动添加硬装项目。导出业主清单不能包含内部字段，分享链接也不能泄漏内部价格。

## 界面和验证

保留现有应用的布局与主要操作。在左侧家具目录中点击类别或家具卡片，立即在其下方展开对应的真实商品列表；列表显示 SKU、名称、尺寸、材质、销售价、商家与详细备注，并可摆放或替换。内部管理员视图另可查看供货价和费率。商品管理员界面提供文件选择、资料填写、模型预览、尺寸/朝向校准和审核。方案页展示三档预算乘三种风格，明确显示超预算、缺项与模型待审核。删除右下角“AI资源网”链接及 README 中相应推广内容。

验证先使用仓库现有户型、两家商家、真实 GLB、无模型照片样品，检查导入/重启持久化、九方案差异、替换后的 SKU/报价、内部价隔离、导出和失败恢复。没有云端环境时，照片生成流程使用本地假响应进行集成验证，并明确标注真实服务未验证。
